# Maintenance source and distribution

Scope: gareth-os-operator and gareth-os-optimizer, modernized under Gareth's 2026-09-16 request. The editable source for these two skills is plugins/os-suite/skills in this repository. Vault Skills copies are generated distribution copies. This scoped maintenance decision follows the user's current GitHub-source intent and supersedes the older vault-first editing convention for these two skills only. Other skills and global governance need their own reconciliation.

Keep task knowledge in portable Markdown and references. Host adapters supply local workspace paths, discovery, permissions, connector schemas, scheduling and rendering. The vault's Resources/prompts/operator-prompt.md is a local launcher pointing to the generated portable procedure.

Before distribution, compare the destination hash against the recorded previous version, preserve every unique local change, copy only reviewed files and read them back. Never hand-edit application-managed caches. Publication, plugin refresh and fresh-session invocation are separate evidence states. A local source change does not prove GitHub publication or Cowork/Claude Code availability.

Historical framework references remain for provenance and recovery; the two entrypoints identify the active portable procedures. Standalone local email skills remain private pending reconciliation of operational names/signatures against sanitized archives. No deletion or public inclusion follows from this policy.

For GitHub publication, inspect the exact diff and private-data scope, publish only the intended changes under the user's authorization, then read the remote revision. Refresh each application through its supported plugin route and test in a fresh session. Verify account-library shadow copies separately; a local file inventory cannot establish the cloud library state.
